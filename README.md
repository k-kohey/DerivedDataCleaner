# DerivedData Cleaner

A quiet menu bar app that automatically removes old Xcode build data and frees up disk space.

- Schedule daily or weekly cleanups at a time you choose.
- Choose how many days of unused build data to keep.
- Optionally remove build data for projects that no longer exist.
- Launch at login and catch up on missed cleanups after waking.
- See the last successful cleanup and estimated space freed from the menu bar.
- Review upcoming runs, results, and errors in Settings. Changes save automatically.

Requires **macOS 26 or later**. Cleans Xcode’s default DerivedData folder. Deletion is permanent; choose a time when you aren’t building.
